`Python` · risk-controlled adjudication of refund-claim evidence

Returns APPROVE / REVIEW / DENY on refund-fraud claims with a **distribution-free, finite-sample guarantee on the false-denial rate**, using a cost-derived (not hand-picked) abstention band. Fully instrumented with CI and automated leakage audits.

- **147.9ms/claim** end-to-end latency; 557 tests, byte-identical reproducible reruns
